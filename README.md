# AI Data Analyst Agent using n8n

An AI-powered Data Analyst Agent built with n8n, Google Sheets, an AI Agent, and Gmail.

## Features
- Retrieves data from Google Sheets.
- Uses an AI Agent to answer data-related questions.
- Connects with Gmail to send reports by email.
- Automates parts of the data analysis workflow.

## Workflow
1. A user sends a question through the chat trigger.
2. The AI Agent processes the request.
3. Google Sheets provides the required data.
4. Gmail sends the configured message or report.

## Tech Stack
- n8n
- Google Sheets
- AI Agent
- Gmail

## Setup
1. Download the workflow JSON from this repository.
2. Import it into your n8n workspace.
3. Configure your own Google Sheets and Gmail credentials.
4. Review the workflow settings and test it with sample data.

## Security
Never share API keys, credentials, private webhook URLs, or confidential spreadsheet data publicly.
